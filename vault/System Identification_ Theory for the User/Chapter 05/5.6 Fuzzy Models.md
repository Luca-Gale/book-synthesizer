# 5.6 Fuzzy Models

> [!tip] Pre-Reading Primer
> **Role in Chapter 5**: Section 5.6 shows that **fuzzy rule-based models**—and their tunable **neuro-fuzzy** counterparts—are not an exotic alternative to black-box system identification, but rather a direct, special instance of the nonlinear basis-function expansion $g(\varphi, \theta) = \sum_{k=1}^n \alpha_k g_k(\varphi, \beta, \gamma)$ developed in Sections 5.4 and 5.5. By translating verbal domain intuition ("if voltage is high and speed is fast...") into piecewise-linear membership functions, product inference rules, and center-of-mass defuzzification, fuzzy models construct multidimensional tensor-product basis functions $g_k(\varphi, \beta, \gamma)$ whose location and dilation parameters can be initialized from human physical insight before precedes formal statistical estimation in Section 5.7.

---

## 1. Core Intuition & Engineering Motivation

When modeling complex industrial, biological, or environmental processes, writing down exact first-principles differential equations is often infeasible. Yet human operators, control engineers, and domain experts frequently possess rich **verbal, qualitative descriptions** of how the system behaves—for example:
- *"If it is cold outdoors and the heater has low power, then the room will be cold."*
- *"If it is cold outdoors and the heater has high power, then the room temperature will be normal."*
- *"If it is hot outdoors and the heater has high power, then the room will be hot."*

Introduced by Zadeh (1975), **fuzzy models** provide a mathematical bridge from these imprecise linguistic statements (**fuzzy rule bases**) to a quantitative predictor function $\hat{y}(t) = g(\varphi(t), \theta)$ mapping measured numerical inputs (regressors $\varphi_1 = \text{outdoor temperature}$, $\varphi_2 = \text{heater power}$) to a numerical output prediction ($y = \text{room temperature}$).

To turn a verbal rule base into a mathematical input-output map when concrete sensor readings arrive (say, outdoor temperature $\varphi_1 = 7^\circ\text{C}$ and heater power $\varphi_2 = 100\text{ W}$), a fuzzy model executes a three-stage pipeline:
1. **Fuzzification (Fuzzy Sets & Membership Functions)**: Classical ("crisp") sets force a hard binary threshold—e.g., $7^\circ\text{C}$ is either $100\%$ "cold" or $0\%$ "cold." Fuzzy sets replace binary indicator functions with smooth or piecewise-linear **membership functions** $\mu_A(\varphi) \in [0, 1]$ that quantify the *degree* to which a measurement $\varphi$ belongs to a linguistic attribute $A$ (such as `cold`, `nice`, or `hot`).
2. **Rule Evaluation / Inference (Combining Rules)**: Each linguistic "IF–AND–THEN" rule $j$ checks multiple regressors simultaneously ($\varphi_1 \text{ is } A_{j,1} \text{ AND } \varphi_2 \text{ is } A_{j,2} \dots$). By replacing logical conjunction (`AND`) with algebraic multiplication, the joint applicability (firing strength) of rule $j$ is computed as the product of the individual membership degrees: $\mu_{A_{j,*}}(\varphi) = \prod_{i=1}^d \mu_{A_{j,i}}(\varphi_i)$.
3. **Defuzzification**: Each rule's linguistic conclusion $B_j$ ("room is cold", "motor is fast") is represented by a single characteristic numerical value $\alpha_j$ (such as the peak or center of mass of the output membership function $\mu_{B_j}(y)$). The final crisp prediction $y$ is formed as the applicability-weighted average of all rule conclusions: $y = \sum_{j=1}^p \alpha_j \mu_{A_{j,*}}(\varphi)$.

**Why Ljung Introduces Fuzzy Models Here**:
From a system identification perspective, Ljung demystifies fuzzy logic by stripping away the jargon and exposing its exact algebraic equivalence to the black-box basis-function framework of Section 5.4:
- Each joint rule-applicability function $\mu_{A_{j,*}}(\varphi) = \prod_{i=1}^d \kappa_i(\beta_k^i(\varphi_i - \gamma_k^i))$ is literally a **tensor-product local basis function** $g_k(\varphi, \beta, \gamma)$ of the exact form (5.39)!
- Each defuzzified rule conclusion $\alpha_j$ is literally the **linear coordinate parameter** $\alpha_k$ in the basis expansion $g(\varphi, \theta) = \sum_{k=1}^n \alpha_k g_k(\varphi, \beta, \gamma)$ of (5.32)!
- When the membership parameters $(\alpha_k, \beta_k, \gamma_k)$ are tuned from input-output data, the resulting **neuro-fuzzy model** (Jang and Sun, 1995) is identical in structure to a radial basis network or kernel estimator—with the practical advantage that verbal physical insight provides intelligent initial guesses for the basis centers $\gamma$, dilations $\beta$, and output levels $\alpha$.

## 2. Mathematical Rigor & Derivations

### 2.1 Symbol & Variable Glossary

| Symbol | Meaning / Physical Interpretation | Space / Dimensions |
| :--- | :--- | :--- |
| $\varphi$ | Regression vector of measured explanatory variables $\varphi = [\varphi_1, \dots, \varphi_d]^T$ | $\mathbb{R}^d$ |
| $y$ | Scalar system output to be explained or predicted | $\mathbb{R}$ |
| $A, A_i, A_{j,i}$ | Fuzzy sets (linguistic attributes, e.g., `cold`, `low voltage`) associated with regressor components | Fuzzy sets on $\mathbb{R}$ |
| $B_j$ | Fuzzy set (linguistic conclusion, e.g., `slow`, `medium`, `fast`) for the output in rule $j$ | Fuzzy set on $\mathbb{R}$ |
| $\mu_A(\varphi)$ | Membership function quantifying the degree of membership of regressor $\varphi$ in fuzzy set $A$ | $\mathbb{R} \to [0, 1]$ |
| $\kappa_1(x)$ | Standard piecewise-linear "soft step" mother function | $\mathbb{R} \to [0, 1]$ |
| $\kappa_2(x)$ | Standard piecewise-linear "triangle" mother function | $\mathbb{R} \to [0, 1]$ |
| $\beta, \beta_k^j$ | Scale (dilation) parameter controlling the slope / transition width of a membership function | $\mathbb{R}$ |
| $\gamma, \gamma_k^j$ | Location (translation) parameter controlling the center or midpoint of a membership function | $\mathbb{R}$ |
| $r$ | Number of linguistic attributes (fuzzy sets) partitioning a single scalar regressor variable | $\mathbb{Z}^+$ |
| $p$ (or $n$) | Total number of fuzzy rules in the rule base (number of basis functions in the expansion) | $\mathbb{Z}^+$ |
| $\mu_{A_{j,*}}(\varphi)$ | Joint membership function (firing strength / applicability measure) of rule $j$ for vector $\varphi$ | $\mathbb{R}^d \to [0, 1]$ |
| $\alpha_j$ (or $\alpha_k$) | Numerical conclusion value (center of mass or peak of $\mu_{B_j}(y)$) associated with rule $j$ | $\mathbb{R}$ |
| $g_k(\varphi, \beta, \gamma)$ | Parameterized multidimensional basis function formed by the product of 1D membership functions | $\mathbb{R}^d \to [0, 1]$ |

### 2.2 Formal Definitions, Assumptions & Step-by-Step Derivations

#### 2.2.1 Fuzzy Sets, Mother Membership Functions & Location-Scale Parameterization

Each scalar regressor $\varphi_i$ used in a fuzzy rule base is associated with a family of linguistic **attributes** (such as `cold`, `nice`, `hot`). Mathematically, an attribute $A$ is modeled as a **fuzzy set** characterized by a **membership function** $\mu_A(\varphi) \in [0, 1]$, which specifies the continuous "degree of membership" of a numerical value $\varphi$ in set $A$.

In practice, fuzzy membership functions are typically constructed from simple piecewise-linear mother functions—specifically a **"soft step"** function $\kappa_1(x)$:

$$
\kappa_1(x) = \begin{cases} 1 & \text{for } x < -1 \\ 1 - (x + 1)/2 & \text{for } -1 \le x < 1 \\ 0 & \text{for } 1 \le x \end{cases} \tag{5.51}
$$

or a symmetric **"triangle"** function $\kappa_2(x)$:

$$
\kappa_2(x) = \begin{cases} 0 & \text{for } |x| > 1 \\ 1 - |x| & \text{for } |x| \le 1 \end{cases} \tag{5.52}
$$

> [!note] Algebraic Verification of the Mother Functions $\kappa_1(x)$ and $\kappa_2(x)$
> - **Soft Step $\kappa_1(x)$**: On the transition interval $x \in [-1, 1]$, $\kappa_1(x) = 1 - \frac{x+1}{2} = \frac{1 - x}{2}$. At the left boundary $x = -1$, $\kappa_1(-1) = \frac{1 - (-1)}{2} = 1$. At the midpoint $x = 0$, $\kappa_1(0) = 0.5$. At the right boundary $x = 1$, $\kappa_1(1) = 0$. Notice that replacing $x$ with $-x$ flips the soft step from a *decreasing* ramp (low-pass attribute) to an *increasing* ramp (high-pass attribute).
> - **Triangle $\kappa_2(x)$**: Supported on $[-1, 1]$, rising linearly as $1 + x$ on $[-1, 0]$ to a peak of $\kappa_2(0) = 1$, and falling linearly as $1 - x$ on $[0, 1]$.

By introducing a **scale (dilation) parameter** $\beta$ and a **location (translation) parameter** $\gamma$ exactly as in Section 5.4, the transition step or triangle peak can be positioned at any physical operating point $\gamma$ with any desired transition width:

$$
\mu_A(\varphi) = \kappa_i(\beta(\varphi - \gamma)) \tag{5.53}
$$

Specifically:
- For $\kappa_1(\beta(\varphi - \gamma))$ with $\beta > 0$: the linear transition occurs over $\beta(\varphi - \gamma) \in [-1, 1]$, which corresponds to the physical interval $\varphi \in [\gamma - 1/\beta, \, \gamma + 1/\beta]$ centered at $\gamma$ with total width $2/\beta$ (so $\beta = 2 / \text{width}$). If $\beta < 0$, the ramp increases from $0$ at $\gamma - 1/|\beta|$ to $1$ at $\gamma + 1/|\beta|$.
- For $\kappa_2(\beta(\varphi - \gamma))$ with $\beta > 0$: the triangle has its peak ($1$) at $\varphi = \gamma$ and base support on $[\gamma - 1/\beta, \, \gamma + 1/\beta]$ with half-width $1/\beta$.

#### 2.2.2 Strong Fuzzy Partitions & Outdoor Temperature Example

**Assumption (Strong Fuzzy Partition)**: Ljung restricts attention to collections of attributes $A_i$ ($i = 1, \dots, r$) for a given scalar variable $\varphi$ whose membership degrees sum identically to unity at every point in the domain:

$$
\sum_{i=1}^r \mu_{A_i}(\varphi) = 1, \quad \forall \varphi \tag{5.54}
$$

A collection of fuzzy sets and membership functions satisfying (5.54) is called a **strong fuzzy partition**. Geometrically, this means that as $\varphi$ increases across a transition zone between two adjacent attributes $A_i$ and $A_{i+1}$, the falling linear slope of $\mu_{A_i}(\varphi)$ is exactly compensated by the rising linear slope of $\mu_{A_{i+1}}(\varphi)$.

**Concrete Construction (Outdoor Temperature, Figure 5.4)**:
Suppose outdoor temperature $\varphi$ (in $^\circ\text{C}$) is partitioned into $r = 3$ attributes: `cold`, `nice`, and `hot`:
1. **`cold`**: Any temperature below $5^\circ\text{C}$ is definitely `cold` ($\mu_{\text{cold}} = 1$), any temperature above $15^\circ\text{C}$ is definitely not `cold` ($\mu_{\text{cold}} = 0$), with a linear transition across $[5, 15]$. The midpoint is $\gamma = 10$ and half-width is $1/\beta = 5 \implies \beta = 0.2$:

$$
\mu_{\text{cold}}(\varphi) = \kappa_1(0.2(\varphi - 10))
$$

2. **`nice`**: Modeled as a symmetric triangle centered at $\gamma = 15^\circ\text{C}$ with zero membership below $5^\circ\text{C}$ and above $25^\circ\text{C}$ (half-width $1/\beta = 10 \implies \beta = 0.1$):

$$
\mu_{\text{nice}}(\varphi) = \kappa_2(0.1(\varphi - 15))
$$

3. **`hot`**: Mirrors `cold` across the interval $[15, 25]$, rising linearly from $0$ at $15^\circ\text{C}$ to $1$ at $25^\circ\text{C}$ (midpoint $\gamma = 20$, negative scale $\beta = -0.2$):

$$
\mu_{\text{hot}}(\varphi) = \kappa_1(-0.2(\varphi - 20))
$$

> - **Strong Partition Check**: At any temperature $\varphi$ (for instance $\varphi = 7^\circ\text{C}$, where $\mu_{\text{cold}}(7) = 0.8$, $\mu_{\text{nice}}(7) = 0.2$, $\mu_{\text{hot}}(7) = 0$), the vertical coordinates of the three curves sum to exactly $1$, verifying (5.54).

#### 2.2.3 Combining Rules, Rule-Base Completeness & Defuzzification

Now consider a $d$-dimensional regression vector $\varphi = [\varphi_1, \dots, \varphi_d]^T$ and a scalar output $y$. A fuzzy rule base containing $p$ rules is written formally as:

$$
\begin{aligned}
\text{if } (\varphi_1 \text{ is } A_{1,1}) \dots \text{ and } (\varphi_d \text{ is } A_{1,d}) &\text{ then } (y \text{ is } B_1) \\
&\;\;\vdots \\
\text{if } (\varphi_1 \text{ is } A_{p,1}) \dots \text{ and } (\varphi_d \text{ is } A_{p,d}) &\text{ then } (y \text{ is } B_p)
\end{aligned} \tag{5.55}
$$

Here the fuzzy sets $A_{j,i}$ are doubly indexed:
- $j \in \{1, \dots, p\}$ indexes the **rule** in the rule base.
- $i \in \{1, \dots, d\}$ indexes the **regressor variable** (measurement component $\varphi_i$).
The corresponding input and output membership functions are denoted $\mu_{A_{j,i}}(\varphi_i)$ and $\mu_{B_j}(y)$, respectively.

**Assumption (Complete Rule Base)**: We assume that the rule base covers every possible combination of attributes across the $d$ regressors. Specifically, if regressor $\varphi_i$ has $r_i$ attributes forming a strong fuzzy partition (5.54), then a **complete** rule base contains $p = \prod_{i=1}^d r_i$ rules (the full Cartesian grid of attribute combinations). Because each regressor's attributes sum to $1$, expanding the product of sums across all $d$ regressors guarantees the multidimensional partition-of-unity identity (Problem 5E.3):

$$
\sum_{j=1}^p \prod_{i=1}^d \mu_{A_{j,i}}(\varphi_i) = \prod_{i=1}^d \left( \sum_{\ell_i=1}^{r_i} \mu_{A_{\ell_i}^{(i)}}(\varphi_i) \right) = \prod_{i=1}^d 1 \equiv 1 \tag{5.56}
$$

**Joint Membership (Rule Applicability)**:
To evaluate how strongly all $d$ conditions ("AND" conjunctions) of rule $j$ hold simultaneously for a given vector $\varphi$, we define the **joint membership function** $\mu_{A_{j,*}}(\varphi)$ as the algebraic product of the individual 1D membership functions:

$$
\mu_{A_{j,*}}(\varphi) = \prod_{i=1}^d \mu_{A_{j,i}}(\varphi_i) \tag{5.57}
$$

This scalar $\mu_{A_{j,*}}(\varphi) \in [0, 1]$ serves as the **measure of applicability** (firing weight) of rule $j$ at regressor point $\varphi$.

**Defuzzification (Weighted-Mean Predictor)**:
To produce a crisp numerical prediction $y$, each linguistic conclusion $B_j$ is summarized by a single characteristic scalar $\alpha_j$—chosen as either the **center of mass** of the output membership function $\mu_{B_j}(y)$ or the value of $y$ at which $\mu_{B_j}(y)$ attains its **peak**. Combining all $p$ rules by weighting each rule's characteristic conclusion $\alpha_j$ by its applicability $\mu_{A_{j,*}}(\varphi)$ yields:

$$
y = \sum_{j=1}^p \alpha_j \mu_{A_{j,*}}(\varphi) \tag{5.58}
$$

Because $\sum_{j=1}^p \mu_{A_{j,*}}(\varphi) \equiv 1$ by (5.56) and (5.57), no denominator $\sum_{j=1}^p \mu_{A_{j,*}}(\varphi)$ is required: (5.58) is automatically a properly normalized convex combination (weighted mean) of the average rule conclusions $\alpha_j$.

#### 2.2.4 Walkthrough of Example 5.4: A DC-Motor

Ljung illustrates the entire pipeline on a discrete-time DC motor with input voltage $u(t)$ and output angular velocity $y(t)$:
1. **Regressors ($d = 2$)**: We predict current angular velocity $y(t)$ from the previous applied voltage and previous angular velocity:

$$
\varphi(t) = [\varphi_1(t), \, \varphi_2(t)]^T = [u(t-1), \, y(t-1)]^T
$$

2. **Input Attributes & Strong Fuzzy Partitions ($r_1 = 2, r_2 = 2 \implies p = 2 \times 2 = 4$ rules)**:
   - **Voltage $\varphi_1(t) = u(t-1)$** has two attributes (`low voltage` in rules $j=1,2$ and `high voltage` in rules $j=3,4$) with transition break points at $1\text{ V}$ and $5\text{ V}$ (midpoint $\gamma_1 = 3$, half-width $2 \implies \beta_1 = 0.5$):

$$
\mu_{A_{1,1}}(\varphi_1) = \mu_{A_{2,1}}(\varphi_1) = \kappa_1(0.5(\varphi_1 - 3)) \quad (\text{"low voltage"})
$$

$$
\mu_{A_{3,1}}(\varphi_1) = \mu_{A_{4,1}}(\varphi_1) = 1 - \mu_{A_{1,1}}(\varphi_1) = \kappa_1(-0.5(\varphi_1 - 3)) \quad (\text{"high voltage"})
$$

   - **Past Speed $\varphi_2(t) = y(t-1)$** has two attributes (`slow speed` in rules $j=1,3$ and `fast speed` in rules $j=2,4$) with break points at $8\text{ rad/sec}$ and $15\text{ rad/sec}$ (midpoint $\gamma_2 = 11.5$, half-width $3.5 \implies \beta_2 = 1/3.5 = 2/7$):

$$
\mu_{A_{1,2}}(\varphi_2) = \mu_{A_{3,2}}(\varphi_2) = \kappa_1\!\left(\frac{2}{7}(\varphi_2 - 11.5)\right) \quad (\text{"slow speed"})
$$

$$
\mu_{A_{2,2}}(\varphi_2) = \mu_{A_{4,2}}(\varphi_2) = 1 - \mu_{A_{1,2}}(\varphi_2) = \kappa_1\!\left(-\frac{2}{7}(\varphi_2 - 11.5)\right) \quad (\text{"fast speed"})
$$

3. **Output Conclusions & Rule Base**:
   The output velocity $y(t)$ is described by three triangular fuzzy sets (`slow`, `medium`, `fast`) shaped like $\kappa_2$ in (5.52) with peaks at $5$, $10$, and $20\text{ rad/sec}$, giving defuzzified rule conclusions $\alpha_1 = 5$, $\alpha_2 = 10$, $\alpha_3 = 10$, $\alpha_4 = 20$:
   - **Rule 1**: If $\varphi_1(t)$ is `low` and $\varphi_2(t)$ is `slow` then $y(t)$ is `slow` ($\alpha_1 = 5$).
   - **Rule 2**: If $\varphi_1(t)$ is `low` and $\varphi_2(t)$ is `fast` then $y(t)$ is `medium` ($\alpha_2 = 10$).
   - **Rule 3**: If $\varphi_1(t)$ is `high` and $\varphi_2(t)$ is `slow` then $y(t)$ is `medium` ($\alpha_3 = 10$).
   - **Rule 4**: If $\varphi_1(t)$ is `high` and $\varphi_2(t)$ is `fast` then $y(t)$ is `fast` ($\alpha_4 = 20$).

![[assets/fig_5_6_dc_motor_membership_functions.png]]

> [!tip] How to Read This Diagram (Figure 5.5)
> - **Top Row**: Membership functions for input voltage $\varphi_1(t) = u(t-1)$ over break points $1\text{ V}$ and $5\text{ V}$. The left plot (`u(t-1) high`) rises linearly from $0$ at $1\text{ V}$ to $1$ at $5\text{ V}$; the right plot (`u(t-1) low`) falls linearly from $1$ at $1\text{ V}$ to $0$ at $5\text{ V}$.

> - **Complementary Symmetry**: Each horizontal pair sums to $1$ at every input value, forming a 1D strong fuzzy partition (5.54) for each regressor.

4. **Numerical Prediction at $\varphi(t) = [4, \, 17]^T$**:
   Suppose at time $t$ the applied voltage is $\varphi_1(t) = 4\text{ V}$ and the past velocity is $\varphi_2(t) = 17\text{ rad/sec}$:
   - **Fuzzify $\varphi_1 = 4$**: Since $4$ lies three-quarters of the way from $1$ to $5$,

$$
\mu_{\text{low}}(4) = \kappa_1(0.5(4 - 3)) = \kappa_1(0.5) = 1 - \frac{1.5}{2} = 0.25, \qquad \mu_{\text{high}}(4) = 1 - 0.25 = 0.75
$$

   - **Fuzzify $\varphi_2 = 17$**: Since $17 > 15\text{ rad/sec}$,

$$
\mu_{\text{slow}}(17) = 0, \qquad \mu_{\text{fast}}(17) = 1
$$

   - **Combine & Defuzzify via (5.58)**: Evaluating the four products $\mu_{A_{j,1}}(4)\cdot\mu_{A_{j,2}}(17)$ and weighting by $[\alpha_1, \alpha_2, \alpha_3, \alpha_4] = [5, 10, 10, 20]$ yields:

$$
y(t) = 5 \cdot (0.25 \cdot 0) + 10 \cdot (0.25 \cdot 1) + 10 \cdot (0.75 \cdot 0) + 20 \cdot (0.75 \cdot 1) = 0 + 2.5 + 0 + 15 = 17.5\text{ rad/sec}
$$

#### 2.2.5 Back to the General Black-Box Formulation (Neuro-Fuzzy Equivalence)

When a fuzzy rule base is calibrated against measured input-output data $Z^N$ ("neuro-fuzzy modeling"), we treat some or all of the defuzzified rule conclusions $\alpha_k$ and the membership scale/location parameters $(\beta, \gamma)$ in (5.53) as tunable parameters $\theta$. Writing $n = p$ for the number of rules, the fuzzy predictor (5.58) takes the exact black-box basis expansion form of Section 5.4:

$$
y = g(\varphi, \theta) = \sum_{k=1}^n \alpha_k g_k(\varphi, \beta, \gamma) \tag{5.59}
$$

where the $k$-th multidimensional basis function $g_k(\varphi, \beta, \gamma)$ is constructed from the parameterized 1D mother membership functions via the product rule (5.57):

$$
g_k(\varphi, \beta, \gamma) = \prod_{j=1}^d \kappa_j\!\left(\beta_k^j(\varphi_j - \gamma_k^j)\right) \tag{5.60}
$$

*(Note: In (5.60), Ljung uses $j = 1, \dots, d$ to index the regressor components $\varphi_j$ and $k = 1, \dots, n$ to index the rule / basis function.)*

**Three Fundamental Structural Connections**:
1. **Equivalence to Tensor-Product Basis Expansion (5.39)**: Equation (5.60) is identical to the tensor-product construction $g_k(\varphi) = \prod_{j=1}^d \kappa(\beta_k^j(\varphi_j - \gamma_k^j))$ in (5.39) of Section 5.4. Thus, *fuzzy models are simply particular instances of the general nonlinear black-box model structure (5.32)–(5.34)*.
2. **Parameter Constraints & Linear Regression Special Case**: Normally, not all parameters $(\alpha_k, \beta_k, \gamma_k)$ should be varied independently—for example, maintaining the completeness/partition identity (5.56) couples the scale and location parameters $(\beta_k^j, \gamma_k^j)$ across adjacent rules so that transition break points continue to align. If the input fuzzy partition is held **fixed** ($\beta$ and $\gamma$ fixed from prior domain knowledge) and only the output conclusions $\alpha_k$ are estimated, then (5.59) reduces to a **kernel estimate (5.49)** and is a **linear regression model** $\hat{y}(t|\theta) = \theta^T \tilde{\varphi}(t)$ in the parameters $\theta = [\alpha_1, \dots, \alpha_n]^T$!
3. **Value and Fragility of Prior Domain Insight**: The chief practical advantage of the fuzzy formulation is that verbal physical insight translates directly into sensible initial values for the basis functions $g_k$ (their locations $\gamma_k^j$, dilations $\beta_k^j$, and output levels $\alpha_k$). However, if too many parameters are freed for unconstrained numerical optimization, the physical meaning encoded in the original rule base can be completely erased—for instance, in Example 5.4, if the output levels $(5, 10, 10, 20)$ are replaced by four unconstrained parameters $\alpha_1, \dots, \alpha_4$ estimated from data, the prior knowledge about which combinations produce "high speed" is no longer utilized by the model structure.

## 3. Pre-Reading Compass (What to Watch Out For)

> [!warning] Key Conceptual Leaps & Notation Traps
> - **Conceptual Leap — Why No Denominator Appears in the Defuzzifier (5.58)**: If you have seen Takagi-Sugeno or Mamdani fuzzy controllers elsewhere, you are used to seeing the center-of-gravity formula $y = \frac{\sum_{j=1}^p \alpha_j \mu_{A_{j,*}}(\varphi)}{\sum_{j=1}^p \mu_{A_{j,*}}(\varphi)}$. Ljung eliminates the rational denominator by enforcing two structural assumptions upfront: a **strong fuzzy partition** (5.54) on each regressor and a **complete rule base** (5.56). Together with product inference (5.57), these force the denominator $\sum_{j=1}^p \mu_{A_{j,*}}(\varphi) \equiv 1$ everywhere, turning a rational nonlinear function into a direct linear combination of tensor-product basis functions (5.59).
> - **Notation Trap — Index Swap Between (5.55)–(5.58) and (5.59)–(5.60)**:
>   - In (5.55)–(5.58), $j \in \{1, \dots, p\}$ indexes the **rule**, while $i \in \{1, \dots, d\}$ indexes the **regressor variable** $\varphi_i$.
>   - In (5.59)–(5.60), Ljung switches back to the notation of Section 5.4: $k \in \{1, \dots, n\}$ indexes the **rule / basis function**, while $j \in \{1, \dots, d\}$ indexes the **regressor variable** $\varphi_j$. Keep this index swap in mind when comparing (5.57) and (5.60).
> - **Curse of Dimensionality in Complete Rule Bases**: Because a complete rule base requires $p = \prod_{i=1}^d r_i$ rules, dividing $d$ regressors into $r$ attributes each yields $p = r^d$ basis functions—the exact tensor-product curse of dimensionality noted in Section 5.4.
> - **Questions to Keep in Mind While Reading**:
>   1. *When we fix the input membership functions ($\beta, \gamma$ fixed) and only estimate the rule conclusions $\alpha_k$, why does (5.59) become so easy to estimate, and how does it compare to the Nadaraya-Watson kernel estimator (5.49)?*
>   2. *Why does freeing all parameters $(\alpha_k, \beta_k, \gamma_k)$ during training risk destroying the linguistic interpretability of the rule base?*
